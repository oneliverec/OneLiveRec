## Overview

OneLiveRec is a modern live stream recording application built with Rust.

It provides automatic live stream monitoring, intelligent stream selection, reliable recording, and powerful automation features for creators, communities, and archival workflows.

With support for hundreds of live platforms, OneLiveRec makes it easy to capture live content continuously with minimal configuration.

---

## Features

### 🚀 High Performance

- Built with Rust for speed and reliability
- Efficient resource usage
- Designed for long-running recording tasks
- Supports multiple concurrent recordings

---

### 🎥 Automatic Recording

Never miss a live stream.

- Automatically monitor live channels
- Start recording when streams go online
- Stop recording when streams end
- Configure recording rules and conditions
- Run scheduled recording tasks

---

### 🎯 Intelligent Stream Selection

Automatically choose the best available stream.

Select streams based on:

- Resolution
- Frame rate
- Bitrate
- Codec
- Container format
- Stream URL priority

Set your preferred quality and fallback strategy.

---

### 🔄 Reliable Stream Handling

Built for unstable live streaming environments.

- Automatic reconnect
- Stream recovery
- Seamless stream joining
- Reduced recording interruptions
- Long-running recording stability

---

### 🛠 Automatic Repair

Improve recording reliability with built-in recovery features.

- Fix common stream issues
- Repair timestamps
- Improve playback compatibility
- Reduce corrupted recordings

---

### 📦 Flexible Output Formats

Supported containers:

- MP4
- MKV
- FLV
- MPEG-TS
- fMP4

Supported video codecs:

- AVC / H.264
- HEVC / H.265
- AV1

### ⚙️ Powerful Management

- Modern user interface
- Bulk channel management
