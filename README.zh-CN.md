## 简介

OneLiveRec 是一款现代化的直播录制应用，基于 Rust 构建。

它提供自动直播监控、智能直播流选择、稳定录制以及强大的自动化功能，适用于个人收藏、内容归档、直播监控以及自动化录制场景。

支持数百个直播平台，让你可以轻松持续录制直播内容，无需复杂配置。

---

# 功能特性

## 🚀 高性能

- 基于 Rust 构建，性能高效稳定
- 低资源占用
- 专为长时间运行设计
- 支持多路直播同时录制

---

## 🎥 自动录制

不错过任何一场直播。

支持：

- 自动监控直播频道
- 开播自动开始录制
- 下播自动结束录制
- 根据条件自动执行录制任务
- 定时录制任务

---

## 🎯 智能直播流选择

自动选择最佳直播流。

支持根据以下条件选择直播流：

- 分辨率
- 帧率
- 比特率
- 编码格式
- 容器格式
- 直播流 URL 优先级

可以自定义画质优先级和备用策略。

---

## 🔄 稳定的直播流处理

针对直播环境中的不稳定情况进行优化。

支持：

- 自动重连
- 直播流恢复
- 无损无缝拼接片段
- 减少录制中断
- 长时间稳定运行

---

## 🛠 自动修复

提高录制文件可靠性。

支持：

- 修复常见直播流问题
- 修复时间戳异常
- 提升播放器兼容性
- 降低录制文件损坏风险

---

## 📦 灵活的输出格式

支持以下容器格式：

- MP4
- MKV
- FLV
- MPEG-TS
- fMP4

支持以下视频编码：

- AVC / H.264
- HEVC / H.265
- AV1
